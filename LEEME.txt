PROYECTO INTEGRADOR - SISTEMA DE ADMINISTRACION DE UN CLUB DEPORTIVO
=====================================================================

MIGRACION TECNOLOGICA
----------------------

Esta versión es una migración del sistema original:

    C# + .NET Framework 4.8 + Windows Forms + MySQL

a una arquitectura más moderna y multiplataforma:

    C# + .NET 10 + Avalonia UI + SQLite

Además, mantiene la separación por capas:

    Entidades -> Datos -> Negocio -> Interfaz Avalonia

La aplicación actual crea y utiliza una base SQLite local automáticamente.
Los datos de prueba del sistema original se cargan al inicializar la base.

COMO ABRIRLO (Visual Studio 2019 o superior):

1. Abrir `ClubDeportivo/ClubDeportivo.sln`.

2. Restaurar los paquetes NuGet si el IDE lo solicita.

3. Ejecutar el proyecto `ClubDeportivo`.

La base SQLite se guarda junto con la salida de compilación como
`clubdeportivo.db`. También se puede indicar otra ubicación mediante la
variable de entorno `CLUBDEPORTIVO_DATABASE_PATH`.
